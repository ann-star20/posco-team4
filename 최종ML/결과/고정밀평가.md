# 고정밀 모드 점검 (배포 코드로, 5-겹 교차검증 1회)

접힘마다 GP 를 새로 학습하고 TabPFN 문맥도 그 접힘의 학습 점만 사용. 불확실도는 GP 보정 배율이 적용된 σ.

| 출력 | 기본(GP) RMSE | 고정밀 RMSE | 기본 2σ 포함 / 오차÷σ | 고정밀 2σ 포함 / 오차÷σ (보정 전) | 고정밀 보정배율 → 보정 후 2σ 포함 |
|---|---|---|---|---|---|
| vth (mV) | 2.24 | 2.18 | 97 % / 0.92 | 97 % / 0.98 | 1.00 → 97 % |
| gm (%) | 0.552 | 0.549 | 98 % / 0.87 | 91 % / 1.27 | 1.27 → 96 % |
| id4v (%) | 0.986 | 1 | 94 % / 0.94 | 94 % / 1.07 | 1.07 → 94 % |
| bv (V) | 0.157 | 0.126 | 94 % / 1.10 | 92 % / 1.55 | 1.55 → 97 % |
