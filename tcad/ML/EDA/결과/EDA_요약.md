# 최종 학습데이터 EDA (학습데이터_최종.csv)

표 안의 "최소 / 5 % / 중앙 / 95 % / 최대"는 이 순서의 분위수다. 코드: `대량작업2/EDA/EDA.py`. 1~5절은 대량 실행 샘플, 6절은 단일 노브 점이다.

## 0. 최종 파일 구성

- 전체 188행 = 대량 실행 146행 + 단일 노브 42행. BV 가 있는 행 98개 (대량 실행 67개 + 단일 노브 31개).
- 학습 영역(`in_domain`) 안 176행, 단일 노브 중 외삽시험용(±30 % 바깥) 24행.

## 1. 대량 실행 샘플의 구성과 품질

- 샘플 146개: 코어 96개(기준값 1개 포함), 확장 50개. 확장 팔별: 바디도즈+ 8, 산화막+ 6, 산화막− 6, 에피도핑+ 14, 에피도핑− 16
- 상태 ok 146개. 규칙 I1·I2·I5·I6·B4 를 모두 통과한 샘플 146개. 재시도한 샘플 1개 (B004).
- 학습 영역(`in_domain`) 안: 143/146. 게이트 스윕 6 V 샘플 20개.
- **영역 밖으로 표시된 샘플 3개**: B126(도즈 0.75, 에피 1.69, BV 21.9 V), B128(도즈 0.74, 에피 1.69, BV 20.2 V), B129(도즈 0.72, 에피 1.50, BV 26.8 V). 바디 도즈가 낮고 에피가 높은 구석에서 BV 가 무너져(서로게이트 예측과 5~13 V 차이) 규칙 "도즈 < 0.8 이고 에피 > 1.4"를 영역에서 뺐다. TCAD 가 낸 실제 값이라 파일에는 남기고 `영역안=False`로 표시한다.
- BV 가 있는 샘플 67개 (46 %). 확장 층은 전부, 코어는 기준값과 바디 도즈 −20 % 이하에만 계산했다 → **BV 가 있고 없는 것이 입력에 의존**한다 (임의 결측이 아님).
- 중복 입력 점 0개, 결측(Vth·gm·Id4V) 0개.

## 2. 입력 커버리지

- 코어 입력끼리의 상관(0에 가까울수록 좋음): 바디 도즈–에피 도핑 -0.10, 바디 도즈–산화막 두께 -0.13, 에피 도핑–산화막 두께 +0.01
- 노브별 범위(비율, 최소~최대): 바디 도즈 0.70~1.68, 에피 도핑 0.30~1.70, 산화막 두께 0.51~1.40
- 코어를 노브별 4등분한 64칸 중 샘플이 있는 칸 48개 (코어 샘플 95개, 칸당 평균 1.5개) → 빈 칸 16개.

- 확장 팔별 샘플 수: 에피도핑− 16, 에피도핑+ 14, 바디도즈+ 8, 산화막− 6, 산화막+ 6 (팔이 짧을수록 적게 배치).

## 3. 출력 분포 (최소 / 5 % / 중앙 / 95 % / 최대)

| 출력 | 값 |
|---|---|
| Vth (V) | 0.96 / 1.40 / 2.20 / 3.46 / 3.96 (n = 146) |
| gm (μS/μm) | 2.82 / 3.47 / 4.59 / 6.19 / 7.92 (n = 146) |
| Id(4V) (μA/μm) | 0.22 / 1.77 / 5.23 / 7.71 / 10.06 (n = 146) |
| BV (V) | 20.20 / 30.21 / 41.66 / 80.31 / 86.17 (n = 67) |

- **Vth 스펙(1.7~2.6 V) 밖: 64/146 (44 %)** (아래쪽 26개, 위쪽 38개). BV 스펙(≥ 40 V) 밖: 31/67 (46 %).
- 코어만 보면 Vth 스펙 밖 37/95 (39 %). 즉 ±30 % 영역에는 **양품과 불량이 섞여 있어** 진단 연습에 알맞다.
- Vg=0 누설 최대 1.7e-14 A/μm (기준 5e-16). 가장 큰 값은 Vth 가 낮은 샘플 B128.

## 4. 입력 → 출력 순위 상관 (스피어만, 대량 실행 샘플)

| | Vth | ln gm | ln Id(4V) | BV(있는 샘플) |
|---|---|---|---|---|
| 바디 도즈 | +0.52 | -0.13 | -0.36 | +0.01 |
| 에피 도핑 | -0.10 | +0.22 | +0.34 | -0.93 |
| 산화막 두께 | +0.75 | -0.92 | -0.77 | +0.33 |

- 읽는 법: Vth 는 바디 도즈·산화막에 크게 반응하고 에피에는 거의 반응하지 않는다. **BV 는 에피에 가장 크게 반응**한다 (구분 가능성 분석의 결론과 같은 방향).

## 5. 모델링에 영향을 주는 점

- **출력 간 중복**: Id(4V)와 gm 의 로그 상관 +0.79, Vth 와 ln Id(4V)의 상관 -0.88. Id(4V)는 Vth 를 거쳐 정해지므로 서로게이트를 2단으로 만든 것이 맞다.
- **거의 꺼진 영역**: Vth > 3 V 인 샘플 21개 (14 %). 이 영역에서 Id(4V)는 0.22~3.12 μA/μm 로 기준(5.2)의 4~60 % 라 특징으로서 신호가 약하다.
- **BV 절벽 근처**: 바디 도즈 ≤ 0.8 인 샘플 29개(BV 전부 계산). 이 구간은 −30 %(0.7) 바깥에서 BV 가 급락하므로 영역 경계에 가까운 점이 중요하다.
- **덧셈 예측과의 차이**(노브 하나씩 결과를 더한 Vth 예측 대비): 평균 -13 mV, 표준편차 86 mV, 최대 |304| mV. 가산성이 완벽하지 않으므로 서로게이트가 조합을 직접 배워야 한다.
- **경계 샘플**: 코어 중 Vth 가 가장 낮은 샘플 B115(1.27 V), 가장 높은 샘플 B100(3.48 V).

## 6. 단일 노브 점

- 42개 (노브마다 ±10~70 % 14점, 확산 시간은 제외). BV 가 있는 점 31개 (BV 가 정의되지 않는 바디 도즈 −70 % 등은 비어 있음).
- Vth 범위 0.13~3.94 V. 대량 실행 샘플이 덮지 않는 **±30 % 바깥 영역**을 보여 주는 점이라 외삽 시험에 쓴다 (24개).
- 학습에 넣을 때는 BV 는 학습 영역 안의 점만 쓰는 것을 권장한다 (영역 밖의 바디 도즈 −40~−60 % 는 BV 가 절벽이라 서로게이트에 해롭다).
