# 최종 학습데이터 EDA 보고서

대상: `대량작업2/학습데이터/결과/학습데이터_최종.csv` (188행 × 26열). 수치 출처: `EDA_요약.md` (코드 `EDA.py`). 모든 데이터는 TCAD(Silvaco Athena+Atlas) 합성 데이터이며 실측이 아니다.

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 구성 | 대량 실행 146행 (코어 96 + 확장 50) + 단일 노브 42행 |
| 입력 | 바디 도즈, 에피 도핑, 산화막 두께 (기준값 대비 비율). 확산 시간은 30분 고정 |
| 출력 | Vth, gm, Id(4V), BV |
| 품질 | 146개 모두 TCAD 정상 완료, 중복·결측 0, 재시도 1개(B004) |
| BV 보유 | 98행 (대량 67 + 단일 노브 31) |
| 영역 밖 표시 | B126·B128·B129 (`영역안=False`) |

**결론**: 양품과 불량이 섞인 데이터라 원인 진단 연습에 적합하다. 노브별 영향 방향이 물리적으로 설명되고, 학습 시 주의할 점(BV 결측 구조, 펀치스루 구석, Id(4V)·Vth 중복)을 확인했다.

## 2. 샘플 구성과 품질

- 코어: ±30 % 라틴 하이퍼큐브 95개 + 기준값 1개.
- 확장: 한 노브만 ±30 % 바깥으로 보낸 팔 — 에피− 16, 에피+ 14, 바디도즈+ 8, 산화막− 6, 산화막+ 6.
- 단일 노브 42개: 노브마다 ±10~70 % 14점. 24개는 ±30 % 바깥이라 외삽 시험용.
- IV 규칙(I1·I2·I5·I6)과 B4를 모두 통과했다.
- **영역 밖 3개**: 바디 도즈가 낮고 에피가 높은 구석(도즈 0.72~0.75, 에피 1.50~1.69)에서 BV가 20~27 V로 무너졌다. 서로게이트 예측과 5~13 V 차이다. 규칙 "도즈 < 0.80 이고 에피 > 1.40"을 영역에서 뺐다. 이 규칙은 3점으로 정한 **잠정안**이고 경계는 도즈 0.75~0.85, 에피 1.36~1.50 사이로만 좁혀졌다.

## 3. 입력 커버리지

![입력 커버리지](그림1_입력커버리지.png)

- 코어 입력끼리 상관은 −0.13~+0.01로 거의 독립이다.
- 노브별 범위(비율): 도즈 0.70~1.68, 에피 0.30~1.70, 산화막 0.51~1.40.
- 코어를 노브별 4등분한 64칸 중 48칸에 샘플이 있다(평균 1.5개). **빈 칸 16개**는 서로게이트의 불확실도가 큰 곳이다.
- 두 노브가 동시에 ±30 %를 벗어나는 모서리 조합은 의도적으로 뽑지 않았다.

## 4. 출력 분포

![출력 분포](그림2_출력분포.png)

| 출력 | 최소 / 5 % / 중앙 / 95 % / 최대 | n |
|---|---|---|
| Vth (V) | 0.96 / 1.40 / 2.20 / 3.46 / 3.96 | 146 |
| gm (μS/μm) | 2.82 / 3.47 / 4.59 / 6.19 / 7.92 | 146 |
| Id(4V) (μA/μm) | 0.22 / 1.77 / 5.23 / 7.71 / 10.06 | 146 |
| BV (V) | 20.20 / 30.21 / 41.66 / 80.31 / 86.17 | 67 |

- Vth 스펙(1.7~2.6 V) 밖 **64/146 (44 %)**, BV 스펙(≥ 40 V) 밖 31/67 (46 %). 코어만 보면 Vth 스펙 밖 37/95 (39 %).
- Vg=0 누설은 최대 1.7e-14 A/μm이고 가장 큰 값은 Vth가 낮은 B128이다.
- BV 분포는 40 V 근처에 몰려 있고 60 V 이상은 에피를 줄인 확장 샘플이 만든 긴 꼬리다.

## 5. 입력과 출력의 관계

![상관](그림3_상관.png)

| 순위 상관 | Vth | ln gm | ln Id(4V) | BV |
|---|---|---|---|---|
| 바디 도즈 | +0.52 | −0.13 | −0.36 | +0.01 |
| 에피 도핑 | −0.10 | +0.22 | +0.34 | **−0.93** |
| 산화막 두께 | **+0.75** | **−0.92** | −0.77 | +0.33 |

![노브별 출력](그림4_노브별출력.png)

- **Vth·gm·Id**: 산화막과 도즈가 지배한다. 에피는 거의 영향이 없다.
- **BV**: 에피가 거의 단독으로 결정한다(에피가 클수록 BV 감소). 바디 도즈 쪽의 BV는 다른 노브 영향으로 흩어져 보인다.
- 따라서 **에피는 BV로만 보이고**, 도즈와 산화막은 Vth·gm에서 서로 비슷한 방향으로 움직여 헷갈린다. 구분 가능성 분석과 같은 결론이다.

## 6. 모델링에 영향을 주는 점

1. **BV 결측은 임의가 아니다.** 확장 샘플과 코어의 일부(기준값, 도즈 −20 % 이하)에만 BV를 계산했다(67/146). 결측 처리 대신 BV 전용 학습 행을 따로 쓴다.
2. **출력 중복.** Vth와 ln Id(4V)의 상관이 −0.93이고 gm과 Id(4V)의 로그 상관이 +0.95다(순위 상관). Id(4V)가 Vth를 거쳐 정해지므로 서로게이트를 2단으로 만든 근거가 된다.
3. **거의 꺼진 영역.** Vth > 3 V가 21개(14 %)이고 이때 Id(4V)가 0.22~3.12 μA/μm로 기준의 4~60 %라 신호가 약하다.
4. **BV 절벽.** 바디 도즈 ≤ 0.8 샘플 29개는 BV가 급락하는 구간과 가깝다. 영역 경계 점이 중요하다.
5. **가산성이 완벽하지 않다.** 노브 효과를 더한 Vth 예측과 실제의 차이가 표준편차 86 mV(최대 304 mV)다. 서로게이트가 조합을 직접 학습해야 한다.
6. **단일 노브 BV 사용.** 영역 밖 점(도즈 −40~−60 % 등)은 BV 절벽이라 BV 학습에는 영역 안 점만 쓴다.

## 7. 한계

- 합성 데이터이며 측정 노이즈(Vth 0.05 V, gm·Id 5 %, BV 0.3 V)와 로트 산포(3 %)는 가정값이다. CSV에는 노이즈가 없고 학습 단계에서 입힌다.
- BV 보유 행이 98개로 적다.
- 모서리 조합과 펀치스루 경계는 점이 적어 근사로 다룬다.
- 확산 시간은 고정이라 진단·보정 대상에서 제외했다.

## 8. 서로게이트 학습 결과(참고)

영역 안 143개 5-겹 교차검증, 2단 GP: Vth 2.3 mV, gm 0.57 %, Id(4V) 1.02 %, BV 0.24 V. BV 목표 0.15 V는 미달이며 BV 불확실도는 진단 시 보정 배율을 곱해 쓴다.
