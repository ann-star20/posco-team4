# 소이탈 평가: 작은 이탈 샘플에서 high_confidence 가 믿을 만한가

- 새 TCAD 샘플 36개 (번호 147~182) 중 규격 밖 35개를 시험 문제로 썼다. 서로게이트는 기존 데이터로만 학습했다 (새 샘플은 학습에 쓰지 않음).
- 측정 = TCAD 출력 + 가정 잡음(웨이퍼 N장 평균), 보정은 에이전트 기본 모드. 보정 후 공정값에 가장 가까운(최대 비율 차이) TCAD 샘플(자기 자신 제외)의 규격 여부로 "보정 성공"을 근사했다.
- 현재 기준: {'p_spec_after': 0.99, 'p_cause': 0.9, 'max_change': 0.15, 'core': (0.7, 1.3), 'max_p_epi': 0.05}
