# 프로젝트 개요: 운영 단계 공정 이상 진단·보정안 제시 (TCAD 기반 가상 팹 PoC)

## 1. 배경

반도체 제조는 초미세화와 고집적화로 포토, 식각, 박막 증착, 이온주입 등 많은 공정이 복잡하게 연결되고, 앞선 공정의 작은 변화가 후속 공정 결과에 영향을 준다. 지금까지는 숙련 엔지니어의 경험과 실제 웨이퍼 반복 실험으로 공정 조건을 찾았지만, 소자가 미세해지고 3차원 구조가 복잡해지면서 실험에 드는 시간과 비용이 늘고 있다. 또한 공정 데이터는 기업의 핵심 기술정보로 관리되어, 대기업이 아닌 환경(중소 소재·부품·장비 기업, 대학, 연구기관)은 공정 최적화 기술을 자체적으로 확보하기 어렵다.[1]

산업계는 이 문제를 AI와 디지털 트윈으로 풀려 하고 있다. SK하이닉스는 2030년을 목표로 자율 팹을 추진하고 있고[2], 삼성전자도 에이전틱 AI와 평택 3D 디지털 트윈 기반의 자율 팹을 추진하고 있다.[3]

본 프로젝트가 다루는 범위는 자율 팹 전체가 아니다. **데이터가 제한된 환경에서 가상 시뮬레이션으로 운영 단계의 공정 이상을 진단하고, 엔지니어의 최종 승인을 지원하는 의사결정 보조 루프**만 다룬다. AI가 스스로 팹을 고치는 것을 목표로 하지 않는다.

## 2. 문제의식이 공유되는 공공 사례: 알스피어(Alsphere)

알세미는 나노종합기술원, 한국과학기술정보연구원(KISTI)과 반도체 공정 AI 플랫폼 '알스피어'를 공동 개발해 나노팹 실증을 완료했다(과기정통부 나노팹 스마트서비스사업). 알세미 발표에 따르면 다음과 같다.[1]

- 실제 웨이퍼 실험에 앞서 가상 환경에서 여러 공정 조건의 결과를 확인해 연구개발 단계의 불필요한 실험을 줄이는 데 초점을 둔다.
- 포토, 식각, 박막, 이온주입 4대 단위 공정의 AI 모델을 개발했고, 실제 실험 결과와의 정합성 평가에서 평균 91.7%의 예측 정확도를 확보했다.
- 물리 시뮬레이션 데이터와 실제 팹 데이터를 결합한 하이브리드 데이터셋을 쓰며, 소자분리(STI) 모듈 같은 연속 공정의 결과도 예측한다.

## 3. 남아 있는 영역: 개발에서 운영으로

기사에서 확인되는 알스피어의 중심은 공정 조건에 따른 결과 예측으로 개발(R&D)을 효율화하는 것이다. 반면 실제 라인이 돌아가는 운영(양산) 단계에서 이상이나 불량이 발생했을 때 그 원인 후보를 추적하고 보정안을 제안하는 흐름은 기사 기준으로 중심 주제로 다뤄지지 않는다. (알스피어에 해당 기능이 없다는 뜻이 아니라, 기사에서 확인되는 범위가 그렇다는 뜻이다.) 본 프로젝트는 이 운영 단계의 원인 진단과 보정안 제시를 소규모로 구현해 구조의 타당성을 확인한다.

## 4. 프로젝트 내용

대상은 트렌치 파워 MOSFET이고, 공정 노브는 산화막 두께, 바디 도즈, 에피 도핑 3개다. 에피 도핑은 입고 웨이퍼로 정해져 레시피로 바꿀 수 없어서 보정은 산화막과 도즈로만 한다.

**구현한 구성요소**
1. **서로게이트 모델**: TCAD(Silvaco Athena/Atlas) 합성 데이터 185점으로 학습한 2단 가우시안 프로세스. 노브 3개에서 Vth, gm, Id(4V), BV와 불확실도를 즉시 계산하고, 학습 영역 밖 입력에는 값을 내지 않는다.
2. **진단 에이전트**: 측정값에서 노브별 원인을 확률로 추정한다. 확신이 70% 미만이면 판정하지 않고 "구분 불가"로 답하며, 다음에 무엇을 재면 좋은지(BV 측정, 웨이퍼 수 증가)를 권고한다.
3. **보정안 제시와 재검증 경로**: 도즈와 산화막의 조정안을 제시한다. 임계값 5개(보정 후 규격 확률, 원인 확률, 보정량, 에피 이탈 확률, 보정 후 노브 범위)를 모두 통과하면 TCAD 재검증을 생략하는 후보로, 하나라도 못 채우면 TCAD 재검증을 요청한다. 임계값은 임시 기준이다.
4. **서비스화**: 위 모델을 HTTP 서비스로 제공하고 Jetson Orin Nano에서 구동했다. 승인 필요 표시(`requires_human_approval`)는 모든 응답에 들어가며, 최종 적용은 엔지니어가 승인하는 정책이다. 승인 화면은 Gateway·Unity 쪽 연동 단계다.

**현재 검증 수준**
- 모델 서비스: Jetson에서 서비스 시험 39개 항목과 Worker 대역 시험을 통과했다(팀원 실행 보고). 응답 시간은 서로게이트 약 6 ms, 진단 약 3.8초.
- TCAD 검증 서비스: 코드는 구현했으나 기본은 가짜 계산이며, 실제 TCAD 연동은 확인하지 않았다.

**정량 결과** (TCAD 합성 데이터, 가정 측정 잡음, 5-겹 교차검증)
- 서로게이트 오차: Vth 2.19 mV, gm 0.56%, Id(4V) 1.02%, BV 0.156 V (BV는 목표 0.15 V에 근소 미달).
- 진단(792건 중 웨이퍼 25장 평균·BV 측정 조건): 86%를 판정했고 판정한 것 중 95%가 정답. 확신하고 틀린 비율은 이 조건에서 5%이며, 조건 전체로는 5~9%다.
- BV를 재지 않으면 에피 도핑을 구분할 수 없어 웨이퍼 수를 늘려도 판정 비율이 약 50%에 머문다.

## 5. 알스피어와의 비교 (기사 기준)

| 구분 | 알스피어 (알세미 발표 기준) | 본 프로젝트 |
|---|---|---|
| 대상 단계 | 개발(R&D) | 운영(양산) |
| 핵심 기능 | 공정 조건의 가상 시험으로 실험 최소화 | 이상 발생 시 원인 확률 진단과 보정안 제시 |
| 데이터 | 물리 시뮬레이션 + 실제 팹 데이터 | TCAD 합성 데이터 |
| 검증 근거 | 실제 실험 대비 정합성 (산정 방식은 기사에 없음) | 합성 데이터 교차검증, 가정 잡음 |
| 불확실한 경우 | 기사에서 확인되지 않음 | "구분 불가" 명시, 임계값 미달 시 TCAD 재검증 |
| 적용 | 나노팹 인프라 실증, 통합 소프트웨어 | 엣지(Jetson) 소규모 구현, 최종 승인은 엔지니어 |
| 향후 | 공정 예측·최적화와 디지털 트윈을 결합한 제조 AI 플랫폼으로 고도화 | 실제 팹 데이터 보정, TCAD 실연동 |

두 사례의 정확도 수치는 데이터와 검증 방식이 달라 직접 비교하지 않는다.

## 6. 한계와 다음 단계

**한계**
- 실제 팹 데이터가 아닌 TCAD 합성 데이터로 구성해, 실제 생산 환경에서의 일반화 성능은 검증하지 않았다. 측정 잡음과 공정 산포는 가정값이다.
- 소스 접촉 정의에 따라 절대값이 Vth 75 mV, 전류 14%까지 달라진다. 모든 샘플이 같은 정의를 쓰므로 노브 간 상대 비교만 유효하다.
- TCAD 재검증 생략 임계값은 임시 기준이다. 소이탈 샘플 35건으로 평가했으나 건수가 적어 오판율을 확정하지 못했다.
- 영역은 십자 모양(한 번에 한 노브만 ±30%를 넘는 경우까지)이어서, 두 노브가 동시에 크게 벗어나면 맞는 답이 후보에 없을 수 있다.

**다음 단계**
1. 시뮬레이터 설정(이동도 모델, 계면 트랩, 메쉬 등)을 바꾼 TCAD로 모델 불일치 시험 수행.
2. Gateway와 TCAD 검증 서비스의 실연동, 실제 Worker 연동 확인.
3. Jetson에서 고정밀 모드(GP+TabPFN) 설치와 검증, 현재 번들 기준 전체 시험 재실행.
4. 실제 팹 데이터로 가정 잡음과 판정 기준 보정.
