# 최종 ML (서로게이트): 2단 GP

TCAD 대신 노브 3개(바디 도즈, 에피 도핑, 산화막 두께, 기준값 대비 비율)에서 Vth, gm, Id(4V), BV 를 즉시 계산하고 불확실도를 함께 내는 모델.
TCAD 합성 데이터(188행)로 학습했고 측정 잡음·공정 산포는 가정값이다. **학습 영역(in_domain) 안에서만 쓴다.**

## 사용 (두 모드는 `ml_파이프라인.py` 의 `TwoStagePipeline` 하나로)
```python
from ml_파이프라인 import TwoStagePipeline
p = TwoStagePipeline()
p.fast_predict(수만개_후보)   # 기본 모드
p.refine(상위_후보)            # 고정밀 모드 (불가하면 기본으로 대체, r['mode'] 에 표시)
```
기본 모드만 직접 쓰려면 (파일 이름이 숫자로 시작해 `import` 문은 못 쓰므로 `importlib` 로 불러온다):
```python
import importlib.util
spec = importlib.util.spec_from_file_location("surrogate", "2단_GP.py")
m = importlib.util.module_from_spec(spec); spec.loader.exec_module(m)
s = m.Surrogate()
r = s.predict([[1.0, 1.0, 1.0], [0.9, 1.1, 1.0]])   # (n,3): [도즈, 에피, 산화막] 비율
r["vth"], r["gm"], r["id4v"], r["bv"]               # V, A/V/μm, A/μm, V
r["sigma_vth"], r["sigma_bv"]                       # 보정된 불확실도 (gm·Id 는 상대값)
r["in_domain"]                                      # 영역 안 여부. strict=True(기본)면 영역 밖은 NaN
```
`python 2단_GP.py` 로 자체 점검, `python 최종ML만들기.py` 로 재학습(약 1~2분).
가능하면 `2단_GP.py` 를 `surrogate.py` 같은 영문 이름으로 바꾸는 것을 권한다 (`ml_파이프라인.py`·`jetson_벤치.py`·`최종ML만들기.py` 는 이름이 바뀌어도 `class Surrogate` 를 찾아서 불러온다).

## 성능 (학습 영역 안, 5-겹 교차검증 2회, 보지 않은 143개)
| 출력 | RMSE | 요구 | 비고 |
|---|---|---|---|
| Vth | 2.19 mV | 25 | 통과 |
| gm | 0.56 % | 2.5 | 통과 |
| Id(4V) | 1.02 % | 2.5 | 통과 (최대 8.9 %: Vth 3.5 V 넘는 거의 꺼진 점) |
| BV | 0.156 V | 0.15 | 근소 미달 (측정 잡음 0.3 V 이내) |

σ 보정배율: Vth 1.0, gm 1.0, Id 1.7, BV 1.68 (보정 후 2σ 포함률 94~98 %).

## 모델 선택 근거 (자세한 내용은 `최종모델_채택보고서.docx`)
- GP 계열 2단 구조가 정확도·과적합 모두 최고. MLP·PhysicsNeMo FC 는 불확실도 과신(2σ 포함률 15~60 %), 딥 GP·LightGBM·다중출력 GP 는 열세.
- BV 는 원래 입력 GP 가 영역 안에서 가장 정확하지만 영역 밖(에피 감소 방향) 외삽이 크게 틀리므로 `in_domain` 안에서만 쓴다.
- GP+TabPFN v2 가중평균(13번)은 영역 안 BV 0.126 V 로 더 정확하지만 44 MB Transformer 와 torch 가 필요하고 TabPFN 은 PC 에서 1만 점에 약 9분이라 탐색에는 쓸 수 없다. 그래서 **기본은 2단 GP, 고정밀 모드는 확인 단계에서만** 쓰도록 두 모드로 만들었다 (`Jetson_흐름.md`).

## 고정밀 모드 성능 (배포 코드로 5-겹 교차검증 1회, `결과/고정밀평가.md`)
| 출력 | 기본(GP) | 고정밀 | 고정밀 σ 보정배율 → 2σ 포함률 |
|---|---|---|---|
| Vth | 2.24 mV | 2.18 mV | 1.00 → 97 % |
| gm | 0.552 % | 0.549 % | 1.27 → 96 % |
| Id(4V) | 0.986 % | 1.00 % | 1.07 → 94 % |
| BV | 0.157 V | **0.126 V** | 1.55 → 97 % |

## Jetson 배포
1. `2단_GP.py`, `jetson_벤치.py`, `모델/` 를 Jetson 으로 복사. 필요한 패키지는 NumPy 하나.
2. `python jetson_벤치.py` 로 속도 확인 (이 PC: 1점 0.49 ms, 10만 점 7.4초. **Jetson 실측은 아직 없음**).
3. **float64 로만 계산한다.** GP 를 float32/FP16(TensorRT 기본)으로 내리면 평균이 0.25~3 까지 어긋난다 (실험 확인).

## 한계
- TCAD 합성 데이터로 학습. 실제 소자·측정과의 비교는 하지 않았다.
- 영역: 코어 ±30 % + 한 노브만 안전 한계까지. 두 노브가 동시에 벗어나는 모서리, 바디 도즈 < 0.8 이고 에피 > 1.4 인 펀치스루 구석(점 3개로 정한 잠정 규칙)은 사용 불가.
- 측정 잡음·공정 산포는 가정값. 잡음 섞인 값으로 다시 학습한다면 GP 잡음항 상한(코드의 `WhiteKernel` 범위)을 넓혀 둔 현재 설정을 유지할 것.
- BV 학습 점 88개. 에피 0.3~0.5 극단에서 오차가 크다.
