# Jetson 테스트 체크리스트

Jetson에 모델을 넣고 **잘 도는지, 값이 PC와 같은지, 얼마나 빠른지, 막혀야 할 때 막히는지**를 확인하는 순서와 합격 기준.
PC 값은 개발 PC(CPU 8코어, Python 3.14, NumPy 2.5)에서 측정한 것이다. 속도 합격선은 PC 값에 여유를 둔 **제안값**이고 정해진 요구 사항이 아니다.

## 0. 준비
- [ ] 복사한 파일: `2단_GP.py`, `jetson_벤치.py`, `jetson_검증.py`, `테스트/jetson_테스트입력.csv`, `모델/gp.npz`, `모델/영역.json`, `모델/모델정보.json` (폴더 구조 그대로)
- [ ] 고정밀 모드도 볼 때만 추가: `고정밀.py`, `ml_파이프라인.py`, `모델/학습배열.npz`, `모델/tabpfn/`
- [ ] `python --version`, `python -c "import numpy; print(numpy.__version__)"` 가 동작 (기본 모드는 NumPy만 필요)
- [ ] 고정밀: `python -c "import torch, tabpfn; print(torch.__version__, torch.cuda.is_available())"` (torch는 JetPack용 NVIDIA 휠)

## 1. 기본 모드 (2단 GP)

| # | 실행 | 확인할 것 | 합격 기준 (PC 값) |
|---|---|---|---|
| 1-1 | `python 2단_GP.py` | 실행 오류 없이 끝남 | `서로게이트 점검 통과: 기준값 예측 Vth 2.260 V, gm 4.599e-06, Id 5.207e-06, BV 41.1 V` 와 같은 줄 |
| 1-2 | `python jetson_검증.py` | 100점 검증 | 아래 항목이 모두 `통과`, 마지막 줄 `== 전체 판정: 모두 통과` |
| 1-3 | `python jetson_벤치.py` | 속도 기록 | 1점 지연, 1천·1만·10만 점 시간을 적어 둔다 (PC: 0.3~0.5 ms / 0.05 s / 0.4~0.6 s / 3.9~7.4 s) |
| 1-4 | 1-2를 두 번 실행해 `jetson_결과.csv` 비교 | 같은 입력이면 같은 출력 | 두 파일의 숫자가 완전히 같음 |

`jetson_검증.py`가 확인하는 항목 (기본 모드):
- [ ] **PC 값과 같다**: 최대 상대 차이 1e-6 이하 (같은 float64 계산이므로 거의 0이어야 한다). 크게 다르면 float32로 계산됐거나 NumPy 구현 차이를 의심.
- [ ] **영역 밖 6점은 NaN**, 영역 안 94점은 값이 있다 (`in_domain`이 PC와 일치).
- [ ] **TCAD 정답 24점**: Vth 20 mV, gm·Id 10 % , BV 1 V 이내 (PC 평균 오차: Vth 0.5 mV, gm 0.4 %, Id 0.02 %). 학습에 쓴 점이라 정확도 시험이 아니라 정상 여부 확인용.
- [ ] **σ가 모두 양수**.

속도 합격선 (제안):
- [ ] 후보 7만 개 평가가 **30초 이내** (10만 점 시간 × 0.7로 환산). 진단 흐름에서 탐색 단계가 몇 초 안에 끝나야 한다.
- [ ] 1점 호출 지연 **50 ms 이내**.

## 2. 고정밀 모드 (GP + TabPFN) — 설치했을 때만

| # | 실행 | 확인할 것 | 합격 기준 |
|---|---|---|---|
| 2-1 | `python 고정밀.py` | 합치기 규칙 점검 | `합치기 규칙 점검 통과` |
| 2-2 | `python ml_파이프라인.py` | 두 모드 시연 | 첫 줄 `고정밀 모드: 사용 가능`, 마지막 3줄에 GP 값과 합친 값이 같은 값 근처로 출력. PC: 기본 3만 후보 1.2~1.4초, 상위 20개 확인 9~10초 |
| 2-3 | `python jetson_검증.py` 의 고정밀 부분 | 12점 비교 | `통과 고정밀 값이 PC 값과 비슷하다` (Vth 5 mV, BV 0.3 V 이내 허용 — GPU와 CPU의 수치 차이 감안) |

- [ ] 고정밀 12점 확인이 **60초 이내** (제안). PC는 약 10초이고 호출당 고정 비용(약 6초)이 지배적이다.
- [ ] `torch.cuda.is_available()`이 True인지 기록 (GPU로 돌았는지). GPU에서 실제로 빨라지는지는 이번에 처음 확인하는 항목이다.
- [ ] **고정밀을 쓸 수 없을 때 자동 대체**: 고정밀을 일부러 못 쓰게(예: `모델/tabpfn` 폴더 이름을 잠시 바꾸거나 torch 없는 환경) 하고 `ml_파이프라인.py` 실행 → 오류로 멈추지 않고 `기본(2단 GP) — 고정밀 사용 불가 (…)` 로 표시되어야 한다. 시험 후 폴더 이름을 되돌릴 것.

## 3. 기록해서 알려 줄 것

- [ ] `jetson_검증.py` 전체 출력 (특히 실패 항목, 최대 상대 차이, 고정밀 소요 시간)

- [ ] 실패했다면 오류 메시지 마지막 10줄

## 4. 실패했을 때 점검 순서

| 증상 | 가능한 원인 | 조치 |
|---|---|---|
| `ModuleNotFoundError: numpy` | NumPy 미설치 | `pip install numpy` |
| `FileNotFoundError: …gp.npz` | 폴더 구조가 달라짐 | `모델/` 폴더를 코드 옆에 그대로 복사 |
| `StopIteration` (모듈을 못 찾음) | 코드 파일이 같은 폴더에 없음 | `2단_GP.py`, `고정밀.py` 등을 같은 폴더에 둔다 |
| PC 값과 상대 차이가 1e-6보다 큼 | 입력이 float32로 들어가거나 NumPy 버전 차이 | 입력을 float64로, NumPy 버전 기록 |
| 영역 밖인데 값이 나옴 | `strict=False`로 호출했거나 영역.json 손상 | 기본 호출(`strict=True`)로 확인, `영역.json` 다시 복사 |
| 속도가 합격선보다 훨씬 느림 | CPU 전력 모드가 낮음, 백그라운드 부하 | `sudo nvpmodel -m 0`, `sudo jetson_clocks` 후 재측정 (설정 변경이므로 본인 판단으로) |
| 고정밀 `사용 불가 (…)` | torch·tabpfn 미설치, 가중치 경로 | 메시지의 사유 확인 후 설치. 안 되어도 기본 모드는 정상 |
| 고정밀 값이 PC와 크게 다름 | GPU 수치 차이 또는 tabpfn 버전 차이 | `pip show tabpfn`이 9.2.0인지 확인, CPU로도 실행해 비교 |
| 메모리 부족 | 고정밀(torch+TabPFN) | 고정밀 없이 기본 모드만 사용 |

## 5. 이 테스트가 보장하지 않는 것
- 진단 정확도: 이 테스트는 **서로게이트가 Jetson에서 같은 값을 내는지**만 본다. 측정값으로 원인을 맞히는 진단은 아직 만들지 않았다.
- TCAD 24점은 학습에 쓴 점이라 모델의 일반화 성능을 보여 주지 않는다 (성능은 `최종모델_채택보고서.docx`의 교차검증 결과 참조).
- 오래 돌렸을 때의 안정성(메모리 누수, 열)과 전력 소모는 확인하지 않는다.
