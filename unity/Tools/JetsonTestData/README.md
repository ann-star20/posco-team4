# Jetson CSV 시험값 → Unity

## 실행

1. `start-jetson-test-data.cmd` 실행. 계정명은 `jetson`이면 Enter.
2. SSH 비밀번호를 복사/실행 단계에서 각각 입력. 채팅에 보내지 않는다.
3. `UNITY_TEST_DATA_READY` 이후 창을 켜둔다. Ctrl+C로 종료한다.
4. Unity Play 종료 → Ctrl+R → Play.
5. `Jetson CSV 시험값` → `Jetson 데이터 받기`. 기본 `자동 순서` 모드에서는 ID를 고를 필요가 없다.
   정상 → 두께 이상 → 전기특성 이상 순서로 실제 CSV 행을 선택한다. 출처는 선택한 TCAD/PC만 사용한다.
   직접 지정하려면 `직접 선택`으로 바꾸고 ID/출처 선택 → `다음 산화막 검사에 적용`.
6. 기존 엘립소미터 검사 버튼을 누른다. 기존 운송/도킹 조건은 유지된다.

## 통신

Jetson 192.168.213.167에서 Python 표준 라이브러리 서비스가 CSV 100행을 읽는다.
서비스는 Jetson의 127.0.0.1:8601에만 바인딩한다. SSH 로컬 포워딩을 통해
Unity가 http://127.0.0.1:8601/api/v1/test-samples 를 조회한다.
PC 주소가 localhost여도 데이터는 SSH를 통해 Jetson에서 읽는다. PC CSV 대체 읽기는 없다.
영상 8500, AOI 8400, 기존 분석 서버 및 DB에는 변경을 가하지 않는다.
이미 Jetson 8601이 사용 중이면 기존 서비스의 CSV 해시와 전체 응답이 현재 데이터와 일치하는지 확인한다.
일치하면 재시작 없이 재사용하며 새 SSH 창은 터널 유지를 위해 켜둔다. 새 창을 닫아도 기존 서비스는 종료하지 않는다.
응답이 없거나 내용이 다르면 연결을 중단한다. 자동으로 다른 서비스를 종료하지 않는다.

GET 응답: schema_version=1, data_source=jetson_csv_test, dataset_sha256,
epi_semantics=drift_doping_ratio, rows[].
각 행: id, kind, dose_ratio, epi_doping_ratio, oxide_ratio,
has_tcad, has_pc, tcad/pc{vth,gm,id4v,bv}, 고정밀 Vth/BV 참고값과 존재 플래그.
읽기 전용이며 임의 파일 다운로드나 원격 설정 변경 API는 없다.

## 판정과 출처

- 산화막 두께 = 검사 레시피 목표 nm × CSV 산화막 배율.
- CSV에 지점별 두께가 없으므로 3개 지점에 같은 환산값을 표시한다. 노이즈를 생성하지 않는다.
- 두께 판정은 기존 레시피 허용 범위로 수행한다.
- 전기특성은 선택한 TCAD 또는 PC 값 4개를 그대로 사용한다. 없는 TCAD를 PC로 자동 대체하지 않는다.
- PC 고정밀 열은 Vth/BV만 있으므로 서로 다른 출처와 섞어 입력하지 않는다.
- 영역 밖 X 행처럼 전기특성 값이 모두 비어 있는 행은 조건만 볼 수 있고 검사 입력 적용은 차단한다.
- 분석 웨이퍼 수는 CSV에 없어 UI 시험 가정값(기본 1)을 명시한다.
- 도즈는 이온주입 조건, 에피는 투입 웨이퍼의 드리프트 도핑 배율이다. 물리 장비 설정은 바꾸지 않는다.
- CSV 선택은 다음 검사 시작 시 복사되어 고정된다. 검사 중이나 분석 요청 대기 중에는 변경하지 않는다.
- 자동 순서는 새 OHT 투입에서 다음 행으로 넘어간다. OHT 없이 검사하면 `새 시험 웨이퍼 준비`로 다음 시험 웨이퍼를 지정한다.
- 같은 웨이퍼 재검사는 기존 행·출처·기준 두께·분석 웨이퍼 수를 유지한다. 설정 변경은 신규 웨이퍼부터 적용된다.
- 자동 결과는 원본 CSV 값과 기존 판정식으로 계산한다. 정상/NG 문구를 강제로 바꾸지 않으며, 기존 HOLD 해제 규칙도 유지한다.
- 자동/직접 선택 모드, 사례 유형, 시험 웨이퍼 식별자와 기준 두께도 로컬 이력에 남는다.
- 기존 Jetson 분석 워커가 연결되어 있을 때 이상 검사만 기존 분석 대기열로 전송된다.
- 실제 계측, TCAD 재검증, 보정 적용, 팀원 DB 저장 완료를 의미하지 않는다.
- 로컬 두께 이력에 sample ID, 전기특성 출처, CSV 해시, 세 노브가 남는다.

## 검증

Python: `test_server.py` (실제 CSV 변환, 결측 TCAD, HTTP 응답, 잘못된 숫자 거부).
PowerShell: `test-protocol.ps1` (단위 환산, 출처 분리, 잘못된 데이터 거부).
PowerShell: `test-auto-sequence.ps1` (3단계 순서, 재검사 고정, 출처/기준 고정, 스냅샷, 불완전 시나리오 차단).
Unity runtime 수동 컴파일로 코드 오류 확인. Jetson 로그인/실행과 실제 Unity 장면 검사는 별도 확인 필요.
오프라인 장면 통합 시험은 프로젝트 루트에 `JetsonCsvAutoCheck.once`를 만든 뒤 Unity가 가져오기를 완료하면 수행한다.
직접 선택과 자동 순서의 판정/분석 대기열/이력/재검사 스냅샷을 임시 이력 저장소로 검사하며, 결과는 `JetsonCsvAutoCheck.result`에 기록한다.
