시연용 실제 TCAD 관리자 확인 승인

1. 신규 GET /api/v1/tcad/proposals에서 in_spec 후보를 선택합니다.
2. 승인자명을 입력하고 선택 후보가 실제 TCAD 결과임을 확인했다는 체크를 합니다.
3. 관리자 승인 요청 → 비밀번호 1234 → 승인 확인.
4. 신규 POST /api/v1/tcad/proposals/{proposal_id}/decision 성공 응답의 공정값과 선택 후보가 일치해야 저장·적용합니다.
5. 후보 변경·목록 재조회·승인자명/공정값 변경 시 기존 확인을 재사용할 수 없습니다.
6. LOT가 공정을 시작할 때 도즈·에피·산화막 조건을 고정합니다. 진행 중인 LOT는 기존 조건을 유지하고 다음 새 LOT부터 승인 조건을 사용합니다.
7. 승인값·관리자 확인·확인 시각·LOT별 조건은 Unity Application.persistentDataPath/demo-approved-lot-recipes.json에 저장됩니다. 재실행해도 읽어옵니다. 비밀번호와 Gateway 토큰은 이 파일에 저장하지 않습니다.
8. CSV 모드에서는 승인 기준값에 기존 CSV 배율을 곱한 시뮬레이션 값으로 계산하며, 일반 시연 모드도 승인 산화막·도즈 기준을 사용합니다. 기존 품질 규격과 CSV 원본 전기특성은 변경하지 않습니다.
9. 에피는 모델 입력 조건으로만 반영하며, 에피 액추에이터는 이 장면에 없습니다.

실제 TCAD 출처는 서버가 보증한 것이 아니라 관리자가 확인한 시연 절차입니다. UNITY_MODE/approval_allowed 레거시 필드는 이 수동 확인을 대체하지 않습니다. Gateway 코드/DB 스키마 변경 없음.
