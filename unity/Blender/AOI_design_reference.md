# AOI line design agreed on 2026-10-15

Status: reference only. Do not start modeling until instructed.

Flow: MOSFET input buffer -> AOI inspection machine -> OK/NG sorter.

Input buffer: bulk MOSFET hopper, vibratory feeder, single-direction alignment guide rails, sensor and stopper/escapement to separate one part at a time, green conveyor feeding AOI at regular spacing. Use the modified MOSFET buffer in the first reference image, rather than the standard PCB magazine buffer.

AOI: enclosed inspection chamber with observation window, conveyor pass-through, independent inspection monitor.

OK/NG collection: follow the second reference image. Two adjacent metal cabinets, each with an upper inclined metal chute, transparent upper side guards, green OK/red NG label and matching indicator, front access/handle, and pull-out compartmented product tray. Do not use loose floor bins.

Reference illustration dimensions (conceptual, not verified manufacturer specifications): each cabinet 450 mm wide x 500 mm deep; lower cabinet 600 mm high and upper guard/chute section about 400 mm; removable tray 400 x 300 x 40 mm.

Preserve independent objects for future animation: feeder/stopper, conveyor products, sorter actuator, access doors, tray drawers and removable trays. Model first; animate later in Unity.
