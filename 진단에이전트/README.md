# 진단 에이전트

이상 로트의 측정값(Vth, gm, Id(4V), 선택적으로 BV)에서 **어떤 공정 노브(바디 도즈, 에피 도핑, 산화막 두께)가 벗어났는지** 확률로 추정하고, 확신이 없으면 **"구분 불가"** 라고 답하며, 다음에 무엇을 재면 좋은지 권고하고, 도즈·산화막으로 보정안을 내고, 마지막에 고정밀 모드로 확인한다.
`최종ML/` 의 서로게이트(`TwoStagePipeline`)를 불러 쓴다. TCAD 합성 데이터로 학습한 서로게이트 기준이며 측정 잡음은 가정값이다.

| 파일 | 내용 |
|---|---|
| `진단에이전트.py` | 에이전트 (`DiagnosisAgent`). `python 진단에이전트.py` 로 자체 점검과 시연 3건 |
| `에이전트평가.py` | 실제 TCAD 샘플로 진단 정확도 평가 (약 10분) → `결과/에이전트평가.md`, `에이전트평가_성능.png`, `에이전트평가.json` |

## 사용
```python
from 진단에이전트 import build_agent        # 파일 이름이 한글이라 importlib 로 불러와도 된다 (진단에이전트.py 의 selftest 참고)
agent, pipe = build_agent()                 # 고정밀 모드를 쓸 수 있으면 함께 불러온다
res = agent.run(dict(vth=2.40, gm=4.1e-6, id4v=4.0e-6, bv=None), n_wafers=5)   # bv 를 안 재었으면 None
print(res["요약문"])                         # res["진단"], ["다음측정"], ["보정안"], ["고정밀확인"], ["TCAD확인요청"]
```
측정값 단위: Vth V, gm A/V/μm, Id(4V) A/μm, BV V. `n_wafers` 는 평균한 웨이퍼 수(잡음이 1/√N 로 줄어든다).

## 흐름 (한 번의 진단, 이 PC에서 약 20초)
1. **후보 격자** 약 5만 개(`in_domain` 안, 간격 0.025)를 기본 모드(2단 GP)로 한 번에 예측해 둔다.
2. **사후분포**: 측정값과의 가우시안 가능도. 분산 = 측정 잡음²/웨이퍼 수 + 서로게이트 σ²(보정됨). 사전분포는 균등(옵션: 희소 `prior_laplace`, 기준값 쪽 `prior_sigma`). 사후분포가 모인 영역은 0.005 간격으로 다시 계산한다.
3. **판정**: 노브 8가지 조합(정상 / 도즈 / 에피 / … / 3개 모두; 기준에서 5 % 넘게 벗어난 노브의 집합) 중 가장 확률 높은 것이 70 % 이상이면 판정, 아니면 **구분 불가**와 후보 목록.
4. **다음 측정 권고**: 사후분포에서 가상의 진실을 뽑아 BV 측정, 웨이퍼 2배·4배를 시뮬레이션하고 판정 가능 비율이 가장 많이 오르는 행동을 권한다.
5. **보정안**: 에피는 제어 불가. 도즈·산화막 배율(기본 ±15 % 이내)을 사후분포 전체에서 기준값 특성(Vth, gm, Id)으로 되돌리는 쪽으로 고른다. 개선이 10 % 미만이면 조정하지 않는다. 에피가 벗어났을 가능성이 높으면 "BV 는 보정되지 않는다"고 경고한다.
6. **고정밀 확인**: 사후 상위 100개 후보와 보정 후 상태를 고정밀 모드(GP+TabPFN)로 한 번에 다시 예측해 판정이 바뀌는지 본다. 고정밀을 쓸 수 없으면 건너뛰고 사유를 알린다.
7. **TCAD 확인 요청**: 보정 후 노브 값을 TCAD로 돌릴 작업(`res["TCAD확인요청"]`)으로 내보낸다. 오케스트레이터 연결은 아직 안 했고 TCAD 확인은 하지 않았다.

## 평가 결과 요약 (`결과/에이전트평가.md`)
시험 문제는 학습 데이터의 실제 TCAD 샘플 176개(영역 안)이고, 측정값 = TCAD 출력 + 가정 잡음(웨이퍼 N장 평균)이다. 5-겹 교차검증으로 접힘마다 서로게이트를 새로 학습해 시험 샘플이 학습에 쓰이지 않게 했다. 진단 792건(균등 사전분포).

| 웨이퍼 N | BV | 판정한 비율 | 판정이 맞은 비율(판정한 것 중) | 확신하고 틀린 비율(전체) |
|---|---|---|---|---|
| 1 | 없음 | 30 % | 81 % | 6 % |
| 1 | 측정 | 48 % | 83 % | 8 % |
| 5 | 없음 | 42 % | 81 % | 8 % |
| 5 | 측정 | 67 % | 90 % | 7 % |
| 25 | 없음 | 49 % | 82 % | 9 % |
| 25 | 측정 | 86 % | 95 % | 5 % |

- **BV 를 재고 웨이퍼가 많을수록 판정이 늘고 정확해진다.** BV 를 안 재면 에피를 알 수 없어 N 을 늘려도 판정 비율이 50 % 정도에 머문다. 이 구조(에피는 BV 로만 보임)가 그대로 재현된다.
- **확률은 대체로 믿을 만하지만 약간 과신한다.** 최다 확률 0.85 이상 구간의 실제 정답률은 94 %, 0.70~0.85 구간은 71 %, 0.55~0.70 구간은 54 %(평균 확률 62 %).
- **90 % 신뢰구간 포함률**은 BV 없음에서 87~93 %, BV 측정에서 81~85 %로 90 % 보다 조금 낮다. 거친 격자(0.025)만 쓰면 사후분포가 좁을 때 포함률이 38~62 % 까지 떨어지는데, 촘촘한 재계산(0.005)으로 88~94 % 로 회복된다(표 7).
- **확신하고 틀린 비율은 5~9 %** 로, 처음 목표로 삼았던 5 % 이하는 N=25 + BV 측정에서만 만족한다.
- **한 노브만 벗어난 경우가 가장 어렵다.** 웨이퍼 5장에서 판정 비율이 10~43 % 이고, 도즈 → 산화막 같은 혼동도 일부 있다(표 5). 시험 문제의 절반 가까이(웨이퍼 5장 기준 176건 중 87건)가 세 노브가 모두 벗어난 무작위 점이라 균등 사전분포에 유리하게 구성되어 있다. 희소 사전분포는 한 노브만 벗어난 경우의 판정을 늘리고(BV 측정, N=5: 판정한 비율 27 % → 42 %, 맞은 비율 29 % → 100 %) 세 노브가 모두 벗어난 경우에는 약간 불리하다(표 8). 실제 공정에서 어느 쪽이 많은지는 실제 데이터가 없어 알 수 없는 가정이다.
- **보정안**: Vth 가 규격 밖이던 60개 중 85 % 가 보정 후 서로게이트 기준으로 규격 안에 든다. 같은 서로게이트로 평가했고 TCAD 확인이 아니므로 낙관적일 수 있다.

## 한계
- 모든 결과는 TCAD 합성 데이터와 서로게이트 기준이다. 실제 측정 데이터로 검증하지 않았다.
- 측정 잡음(Vth 0.05 V, gm·Id 5 %, BV 0.3 V)은 가정값이다. 로트 내 웨이퍼 산포 같은 다른 변동 요인은 모델링하지 않았다.
- 서로게이트의 모델 오차는 웨이퍼를 평균해도 줄지 않으므로 N 이 아주 커져도 구간이 무한정 좁아지지는 않는다(보정된 σ 로 반영).
- 노브 범주의 기준(5 %), 판정 기준(70 %), 사전분포는 설정값이다. 판정이 바뀌므로 용도에 맞게 정해야 한다.
- 영역 밖(`in_domain` 밖)의 상태는 후보에 없다. 실제 이상이 영역 밖이면 맞는 답이 없다. 이때 측정값과 가장 잘 맞는 후보의 가능도가 낮아지지만 이를 별도로 알리는 기능은 아직 없다.
- 고정밀 확인은 호출당 약 10~18초(이 PC, CPU)이고 Jetson 실측은 없다. 시간 제한과 자동 대체 정책은 아직 구현하지 않았다.
- TCAD 확인 요청 작업은 만들어서 내보내기만 하며 오케스트레이터(PostgreSQL 작업 큐)에는 연결하지 않았다.
