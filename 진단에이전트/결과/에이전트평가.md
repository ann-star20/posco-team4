# 진단 에이전트 평가

- 시험 문제: 학습 데이터의 TCAD 샘플 176개 (영역 안; 대량 실행 + 영역 안 단일 노브). 측정값 = TCAD 출력 + 가정 잡음(웨이퍼 N장 평균). 5-겹 교차검증: 시험 샘플은 그 접힘의 서로게이트 학습에 쓰이지 않음.
- 진짜 범주: 노브 비율이 기준에서 5 % 넘게 벗어난 노브의 집합 (8가지). 판정 기준: 최다 범주 확률 ≥ 70 %. 총 진단 792건.
- 측정 잡음은 가정값(Vth 0.05 V, gm·Id 5 %, BV 0.3 V). 진단은 기본 모드(2단 GP)로 했다.

## 1. 웨이퍼 수와 BV 측정에 따른 진단 성능

| 웨이퍼 N | BV | 진단 수 | 판정한 비율 | 판정이 맞은 비율(판정한 것 중) | 확신하고 틀린 비율(전체) | 항상 최다로 답할 때 정확도 | 평균 최다확률 |
|---|---|---|---|---|---|---|---|
| 1 | 없음 | 176 | 30 % | 81 % | 6 % | 51 % | 64 % |
| 1 | 측정함 | 88 | 48 % | 83 % | 8 % | 62 % | 69 % |
| 5 | 없음 | 176 | 42 % | 81 % | 8 % | 56 % | 64 % |
| 5 | 측정함 | 88 | 67 % | 90 % | 7 % | 84 % | 79 % |
| 25 | 없음 | 176 | 49 % | 82 % | 9 % | 69 % | 72 % |
| 25 | 측정함 | 88 | 86 % | 95 % | 5 % | 90 % | 91 % |

판정한 비율이 낮은 것은 오류가 아니라 "구분 불가"로 답한 것이다. 항상 최다 범주로 답하면 정확도가 위 표의 "항상 최다로 답할 때" 값이고, 기준을 넘길 때만 판정하면 맞은 비율이 올라가는 대신 판정 수가 줄어든다.

## 4. 확률이 믿을 만한가 (최다 범주 확률 구간별 실제로 맞은 비율, 전체 진단)

| 최다 확률 구간 | 진단 수 | 실제 맞은 비율 | 평균 최다확률 |
|---|---|---|---|
| 0.00~0.40 | 44 | 23 % | 35 % |

맞은 비율이 평균 확률과 비슷하면 확률을 믿을 수 있다. 훨씬 낮으면 과신, 훨씬 높으면 보수적.

## 6. 보정안 시험 (서로게이트 기준, TCAD 확인 아님)

Vth 가 규격(1.7~2.6 V) 밖이던 시험 샘플 60개(웨이퍼 5장, BV 있으면 측정)에 에이전트가 낸 도즈·산화막 배율을 진짜 노브에 적용해 서로게이트로 예측한 Vth 가 규격 안에 드는 비율: **85 %** (보정 전 0 %).
에피가 벗어난 51건 포함. 평균 도즈 배율 0.973, 산화막 배율 0.977. 같은 서로게이트로 평가했으므로 낙관적일 수 있고 실제 확인은 TCAD 로 해야 한다.

## 7. 촘촘한 격자 재계산의 영향 (웨이퍼 25장, BV 측정함, 마지막 접힘 16개)

| 사후분포 계산 | 도즈 포함률 | 에피 포함률 | 산화막 포함률 |
|---|---|---|---|
| 거친 격자만 (간격 0.025) | 62 % | 38 % | 56 % |
| 촘촘히 다시 계산 (간격 0.005, 에이전트 기본값) | 88 % | 94 % | 94 % |

사후분포가 좁아져 90 % 구간의 폭이 격자 간격(0.025)과 비슷해지면 진짜 값이 격자 점 사이에 있어 포함률이 낮게 나온다. 에이전트는 이를 막으려고 거친 격자로 사후분포의 위치를 찾은 뒤 그 영역을 0.005 간격으로 다시 계산한다. 아래 표 외의 모든 표는 이 재계산을 켠 결과다.
