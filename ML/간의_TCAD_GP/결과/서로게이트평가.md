# 서로게이트 후보 비교 (대량 실행 N=146 중 영역 안 143개 + 단일 노브 점)

- 판정 기준 = 가정 측정 잡음의 0.5배(**가정**): Vth 25 mV, gm 2.5 %, Id(4V) 2.5 %, BV 0.15 V. 오차는 RMS.
- 대량 실행 143개(BV 64개) 위주로 5-겹 교차검증 (학습에는 나머지 대량 실행 + 단일 노브 점 43개를 함께 사용). 선형·다항·GP 는 3회 반복, DNN 은 1회.

## 0. 서로게이트란 (TCAD 와 비교)

TCAD 를 빠르게 흉내 내는 대역 모델이다. 노브를 넣으면 TCAD 처럼 Vth·gm·Id(4V)·BV 를 내고, 불확실도도 함께 낸다.

| | 진짜 TCAD | 서로게이트 (2단 GP) |
|---|---|---|
| 입력 | 노브 3개 (도즈, 에피, 산화막) | 같음 |
| 출력 | Vth, gm, Id(4V), BV | 같음 (+ 예측 불확실도) |
| 속도 | 한 번에 수십 분 | 한 점에 약 0.04 ms (10만 점에 3.9초, 이 PC 기준) |
| 방식 | 물리 방정식을 직접 풂 | TCAD 결과 186개를 보고 입력과 출력의 관계를 학습 |
| 정확도 | 기준(정답) | 교차검증 오차: Vth 2.3 mV, gm 0.57 %, Id(4V) 1.02 %, BV 0.24 V |
| 믿을 수 있는 범위 | 제한 없음 | 학습한 영역(`in_domain`) 안. 바깥에서는 불확실도가 커진다 |

## 1. 교차검증 (학습 영역 안)

| 모델 | Vth(mV) | gm(%) | Id(4V)(%) | BV(V) |
|---|---|---|---|---|
| 선형 | 98.62 | 2.92 | 66.52 | 6.30 |
| 2차다항 | 28.35 | 1.44 ✔ | 30.71 | 2.11 |
| GP | 1.92 ✔ | 0.62 ✔ | 7.69 | 0.15 |
| GP+변환 | 2.33 ✔ | 0.57 ✔ | 6.56 | 0.24 |
| 2단GP | 2.33 ✔ | 0.57 ✔ | 1.02 ✔ | 0.24 |
| DNN앙상블 | 8.38 ✔ | 0.65 ✔ | 2.09 ✔ | 0.23 |

✔ = 기준 이내. (BV 는 BV 를 구한 샘플에서만)

## 2. 외삽 (±30 % 바깥 단일 노브 점 24~30개를 학습에서 빼고 예측), RMS

| 모델 | Vth(mV) | gm(%) | Id(4V)(%) |
|---|---|---|---|
| 선형 | 208.0 | 10.2 | 88.2 |
| 2차다항 | 119.6 | 4.9 | 34.2 |
| GP | 74.1 | 1.8 | 23.7 |
| GP+변환 | 26.5 | 1.7 | 23.3 |
| 2단GP | 26.5 | 1.7 | 9.9 |
| DNN앙상블 | 123.8 | 2.1 | 9.6 |

- 2단 GP 가 외삽 점에서 스스로 알린 Vth 불확실도(평균 7 mV)와 실제 오차(평균 10 mV). 영역 안 교차검증의 실제 오차는 2.3 mV 였다 → 불확실도가 바깥에서 커지면 "범위 밖" 경고로 쓸 수 있다.

## 3. GP 불확실도 보정 (2단 GP, 교차검증에서 실제 오차가 예측 ±2σ 안에 든 비율, 이상적으로 약 95 %)

| 출력 | 비율 |
|---|---|
| Vth(mV) | 98 % |
| gm(%) | 97 % |
| Id(4V)(%) | 89 % |
| BV(V) | 90 % |

## 4. 최종 모델 (2단 GP, 입력 변환)

- 전체 데이터로 학습해 `서로게이트_GP.joblib`에 저장 (학습 점 186개, BV 학습 점 89개).
- 코어 영역 무작위 10만 점을 4개 출력으로 예측하는 데 이 PC에서 **3.88초** (Jetson 시간은 아직 측정 전).
- 사용 영역: `샘플링계획.in_domain()` 안. 진단·보정은 이 함수와 GP 불확실도로 후보를 제한한다.
